# Real damaged digits (test only)

Digits cut from real damaged labels whose true number is known (barcode, reprint or
confirmation): dead print-head lines (9434 6501 0615 1175 6712 91), a faded right half
(9361 2896 8407 0651 6664 25), streaks (9361 2896 8407 0561 8594 81) and a UPS Ground Saver
label (9261 2903 1024 7854 1514 8481 67). Placed by the printed layout fitted to the visible
characters, checked by eye. The digit model never trains on these labels: a new model must
read at least as many of them as the current one.
